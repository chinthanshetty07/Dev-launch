# DevLaunch is starting

The **DevLaunch dashboard** opens in a new browser tab when it is ready — about a minute the
first time. Paste a GitHub repository there and press **Run it**. The project runs here, in
this codespace, and DevLaunch gives you a link to it.

- Didn't open? Open the **Ports** tab below and click the globe next to **DevLaunch dashboard**.
- Something wrong? Run `./devlaunch doctor` in the terminal — it says what, and how to fix it.
- Finished? Stop the codespace (GitHub → Codespaces → Stop) so it does not use your free hours.
