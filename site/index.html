Run any GitHub project on your own computer

Paste a repository. DevLaunch works out how to install and start it, runs it in a locked-down container on your machine, and gives you a link when it answers. Free and open source. No account, nothing sent to us.

Run a repository

That is not a GitHub repository URL. It should look like https://github.com/owner/repo.

This opens DevLaunch on your computer with the repository filled in. Nothing runs until you press Run it there. Not installed yet? See below. Installed but nothing opens? Start it: cd ~/devlaunch && ./devlaunch start

Install once

You need Docker (Docker Desktop, OrbStack or Colima on a Mac; Docker Desktop with WSL2 on Windows; Docker Engine on Linux), Node 20+ and git. Then:

curl -fsSL https://raw.githubusercontent.com/chinthanshetty07/Dev-launch/main/install.sh | bash

It checks what you have, says exactly what is missing and how to get it, and never installs Docker or changes system settings by itself. Then start it:

cd ~/devlaunch && ./devlaunch start

and open http://127.0.0.1:3939.

How it works

  1. Reads the repository — package files, frameworks, the database it needs, its own Dockerfile.
  2. Plans how to run it — by rules for common stacks; optionally with an AI model (your own free Groq key) for the rest.
  3. Runs it in a container — installs, builds and starts it, with databases it needs beside it.
  4. Checks it really works — opens it the way a browser would before calling it ready, and explains plainly when something fails.

Safe on your machine

Locked-down containers

Not root, no extra rights, no access to your files or Docker itself, limits on memory, CPU and processes.

Kept off your network

Code can reach package registries and the internet, but not your home network, your computer or cloud secrets.

Only you can use it

It listens on your computer only, and refuses requests from any website — including this one.

Easy to remove

./devlaunch uninstall takes out everything it added to Docker, and nothing else.

What runs

Node (React, Vite, Next.js, Express…), Python (Flask, Django, FastAPI…), static sites, monorepos and frontend + backend projects, with Postgres, MySQL, MongoDB or Redis when they need one. Projects in other languages run from their own Dockerfile or compose file. Some repositories cannot run as they are (a missing secret key, a broken lockfile); DevLaunch says which and why.

DevLaunch is open source (MIT). Source, issues and docs on GitHub. This page is static: it has no server, no tracking, and never sees what you run.
