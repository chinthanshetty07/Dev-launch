# Code of conduct

DevLaunch is for everyone. In issues, pull requests and anywhere else this project gathers:

- Be respectful and patient, especially with people who are new.
- Criticise code and ideas, never people.
- No harassment, insults, or unwelcome personal attention of any kind.
- Assume good faith; ask before concluding the worst.

Maintainers may edit or remove contributions, and block people, that break these rules. To
report a problem privately, contact the maintainers through the email on their GitHub
profile.
